# Holberton School DevOps Basics

A collection of hands-on DevOps exercises covering containerisation, networking, infrastructure automation, configuration management, load balancing and service resilience.

## Projects

- **exploring_your_first_network** — Docker networking basics.
- **docker_image_optimization** — building smaller and more efficient Docker images.
- **docker_compose_foundations** — multi-container applications with Docker Compose, PostgreSQL, networks, volumes and health checks.
- **load-balancing-resilience-lab** — Nginx load balancing across multiple application instances, round-robin distribution, failover and recovery.
- **terraform-lab** — introduction to infrastructure as code with Terraform.
- **ansible_configuration_management** — configuration management with Ansible, including inventories, SSH connectivity, playbooks, templates, handlers and idempotence.

## Technologies

Docker, Docker Compose, Ansible, Terraform, Nginx, Node.js, PostgreSQL, SSH and Linux.
