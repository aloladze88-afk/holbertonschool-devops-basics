# Infrastructure as Code with Terraform

This project introduces Infrastructure as Code using Terraform and Docker.

The goal is to learn how Terraform can describe, create, update, track, and remove infrastructure resources in a repeatable way. Docker is used locally so the Terraform workflow can be practised without needing a cloud account.

The project also covers Terraform providers, state, plans, resource changes, drift, variables, outputs, and the difference between Terraform and Docker Compose.
