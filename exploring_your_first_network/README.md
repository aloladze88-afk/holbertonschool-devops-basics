# Exploring Your First Network

This project introduces basic Linux networking tools through small Bash scripts. The scripts inspect live network information such as interfaces, addresses, routes, hostname resolution, neighbours, and listening sockets without hardcoding values or changing the system's configuration.

The `list_interfaces.sh` script displays every network interface, its operational state, and its assigned IPv4 and IPv6 addresses in the concise table produced by the Linux `ip` utility.
