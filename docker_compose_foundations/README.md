# Docker Compose Foundations

This project explores how Docker Compose is used to build and manage a multi-container application.

The stack combines a Node.js/Express API, PostgreSQL database, and Nginx reverse proxy. The project covers service communication, isolated networks, persistent database storage, environment-based configuration, healthchecks, service readiness, and controlled host access through a single proxy.

The practical work is completed inside `hbtn-devops-taskflow-node`, starting from the supplied application and progressively building the final Docker Compose stack.
